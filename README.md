# Lista de Tarefas

Aplicação web desenvolvida com **HTML5, CSS3 e JavaScript** para praticar manipulação do DOM, eventos e persistência de dados no navegador.

**[Acessar aplicação](https://annemoura.github.io/lista-de-tarefas-js/)** · **[Ver código-fonte](https://github.com/annemoura/lista-de-tarefas-js)**

## Funcionalidades

- Adicionar novas tarefas.
- Marcar tarefas como concluídas.
- Excluir tarefas.
- Salvar os dados no navegador usando `localStorage`.

## Tecnologias

- HTML5
- CSS3
- JavaScript
- DOM API
- Web Storage API (`localStorage`)

## Conceitos praticados

- Manipulação de elementos do DOM.
- Tratamento de eventos.
- Organização e atualização de listas.
- Persistência de dados no navegador.
- Lógica de programação com JavaScript.

## Executar localmente

1. Clone este repositório.
2. Abra o arquivo `index.html` no navegador.

Não é necessário instalar dependências para executar esta versão.

## Objetivo de aprendizado

Projeto prático desenvolvido para consolidar fundamentos de JavaScript e compreender como uma interface pode responder às ações do usuário e manter informações entre sessões do navegador.
