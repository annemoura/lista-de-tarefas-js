# 📝 Lista de Tarefas

Aplicação web desenvolvida com HTML, CSS e JavaScript.

## 🚀 Funcionalidades
- Adicionar tarefas
- Marcar como concluída
- Excluir tarefas
- Salvar automaticamente no navegador (localStorage)

## 💻 Tecnologias
- HTML5
- CSS3
- JavaScript

## 🔗 Acesse o projeto
https://annemoura.github.io/lista-de-tarefas-js/

## 📌 Sobre o projeto
Este projeto foi desenvolvido com foco em praticar lógica de programação e manipulação do DOM com JavaScript.
